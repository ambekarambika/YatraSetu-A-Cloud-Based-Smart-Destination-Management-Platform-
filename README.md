# YatraSetu — Smart Destination Management Platform

**YatraSetu** is a cloud-based Smart Destination Management Platform designed to address fragmentation in tourism information and destination-management activities. The platform seamlessly integrates tourism information, destination management, stakeholder coordination, tourist feedback, visitor statistics, analytics, reports, and decision-support capabilities into a unified ecosystem.

---

## 🚀 Key Features & User Roles

### 1. 🧳 Tourists
* Explore curated destinations, attractions, and cultural events.
* Create and manage basic trip itineraries.
* Submit verified tourist feedback and reviews.

### 2. 🏛️ Destination Managers
* Manage destinations, attractions, and event listings.
* View visitor statistics and tourist feedback analytics.
* Generate management reports and access decision-support insights.

### 3. 🤝 Tourism Stakeholders
* Share and update tourism service & local facility information.
* Coordinate directly with destination management authorities.

### 4. ⚙️ Administrators
* Role-Based Access Control (RBAC) & User Management.
* Platform content moderation and security oversight.

## 🛠️ Technology Stack

* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Backend**: Python, FastAPI, REST APIs
* **Database**: PostgreSQL
* **Cloud & DevOps**: Render, Google Cloud Platform, Git/GitHub

## 🚦 Getting Started (Sprint 1 Frontend)

1. Navigate to the `frontend/` directory.
2. Open `index.html` in any web browser, or serve locally using Python:
   ```bash
   cd frontend
   python -m http.server 8000
   ```
3. Access `http://localhost:8000` in your web browser.
